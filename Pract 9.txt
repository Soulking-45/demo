ASP.NET MVC Student Application

PART A – CREATE THE PROJECT

Step 1: Open Visual Studio 2019

Open Visual Studio 2019.
Select: Create a new project.

Step 2: Select ASP.NET MVC Project

Search for:
ASP.NET Web Application (.NET Framework)

Select it and click Next.

Step 3: Configure the Project

Project Name:
StudentMVC

Select a suitable location.
Click Create.

Step 4: Select MVC Template

Select:
MVC

Keep the other options at their default values.
Click Create.

PART C – EXISTING CONTROLLER

Open:
Controllers → HomeController.cs

Code:

using System.Web.Mvc;

namespace StudentMVC.Controllers
{
    public class HomeController : Controller
    {
        public ActionResult Index()
        {
            return View();
        }

        public ActionResult About()
        {
            ViewBag.Message = "Your application description page.";
            return View();
        }

        public ActionResult Contact()
        {
            ViewBag.Message = "Your contact page.";
            return View();
        }
    }
}

Important:
Index() is an action method.
return View() displays the corresponding View.

Corresponding view:
Views/Home/Index.cshtml


PART D – MODIFY THE CONTROLLER

Open:
Controllers → HomeController.cs

Add:

public ActionResult Student()
{
    ViewBag.Name = "Rahul";
    ViewBag.Course = "B.Sc. Information Technology";
    ViewBag.RollNo = 101;

    return View();
}

The controller will contain:

public class HomeController : Controller
{
    public ActionResult Index()
    {
        return View();
    }

    public ActionResult Student()
    {
        ViewBag.Name = "Rahul";
        ViewBag.Course = "B.Sc. Information Technology";
        ViewBag.RollNo = 101;

        return View();
    }
}


PART E – CREATE THE VIEW

Right-click Student() inside HomeController.cs.
Select: Add View.

View name:
Student

Select:
Empty (without model)

Click Add.

Visual Studio creates:

Views
└── Home
    └── Student.cshtml


PART F – ADD HTML TO THE VIEW

Open:
Views → Home → Student.cshtml

Replace the contents with:

@{
    ViewBag.Title = "Student Information";
}

<h2>Student Information</h2>

<p><strong>Name:</strong> @ViewBag.Name</p>
<p><strong>Roll Number:</strong> @ViewBag.RollNo</p>
<p><strong>Course:</strong> @ViewBag.Course</p>

@ViewBag.Name gets the value from the Controller.

Controller:
ViewBag.Name = "Rahul";

Output:
Name: Rahul

PART H – MVC ROUTING

URL:
/Home/Student

MVC interprets it as:

/Home/Student
   │       │
   │       └── Action Method
   └────────── Controller

Home → HomeController
Student → Student()

MVC executes:

public ActionResult Student()
{
    ...
    return View();
}

And displays:

Views/Home/Student.cshtml

PART K – ADD AN ACTION TO STUDENTCONTROLLER

Open:
StudentController.cs

using System.Web.Mvc;

namespace StudentMVC.Controllers
{
    public class StudentController : Controller
    {
        public ActionResult Index()
        {
            ViewBag.Message = "Welcome to Student Management";
            return View();
        }

        public ActionResult Details()
        {
            ViewBag.Name = "Priya";
            ViewBag.Course = "B.Sc. Information Technology";
            ViewBag.RollNo = 102;

            return View();
        }
    }
}
