Student CRUD Using ASP.NET MVC

Step 1: Create a New Project

1. Open Visual Studio 2019.
2. Click Create a new project.
3. Select ASP.NET Web Application (.NET Framework).
4. Click Next.

Step 2: Configure Project

Project Name: StudentCRUD
Location: Choose Folder
Framework: .NET Framework 4.7.2

Click Create.

Step 3: Select Template

Choose:
MVC

Authentication:
No Authentication

Click Create.

Step 4: Run the Application

Press:
Ctrl + F5

The default MVC application will open.

Step 5: Install Entity Framework 6

Open:
Tools → NuGet Package Manager → Package Manager Console

Execute:

Install-Package EntityFramework

Step 6: Create Model Class

Right-click Models folder.

Select:
Add → Class

Name:
Student.cs

Write:

using System.ComponentModel.DataAnnotations;

namespace StudentCRUD.Models
{
    public class Student
    {
        [Key]
        public int StudentId { get; set; }

        [Required]
        [StringLength(50)]
        public string Name { get; set; }

        [Range(18, 60)]
        public int Age { get; set; }

        [StringLength(50)]
        public string Course { get; set; }
    }
}

Step 7: Create Database Context Class

Right-click Models folder.

Select:
Add → Class

Name:
StudentContext.cs

Write:

using System.Data.Entity;

namespace StudentCRUD.Models
{
    public class StudentContext : DbContext
    {
        public StudentContext()
            : base("StudentConnection")
        {
        }

        public DbSet<Student> Students
        {
            get;
            set;
        }
    }
}

Step 8: Configure Connection String

Open:
Web.config

Inside <configuration>, add:

<connectionStrings>
    <add name="StudentConnection"
         connectionString="Data Source=(LocalDB)\MSSQLLocalDB;
         Initial Catalog=StudentDB;
         Integrated Security=True"
         providerName="System.Data.SqlClient"/>
</connectionStrings>

Step 9: Enable Migrations

Open Package Manager Console.

Execute:

Enable-Migrations

A Migrations folder will be created.

Step 10: Create Migration

Execute:

Add-Migration InitialCreate

Step 11: Create Database

Execute:

Update-Database

The StudentDB database and Students table will be created automatically.

Step 12: Verify Database

Open:

View → SQL Server Object Explorer

Expand:

(localdb)\MSSQLLocalDB

Understanding Generated Controller Code

Display Records

public ActionResult Index()
{
    return View(db.Students.ToList());
}


Create Record

[HttpPost]
[ValidateAntiForgeryToken]
public ActionResult Create(Student student)
{
    if (ModelState.IsValid)
    {
        db.Students.Add(student);
        db.SaveChanges();
        return RedirectToAction("Index");
    }

    return View(student);
}


Edit Record

db.Entry(student).State = EntityState.Modified;
db.SaveChanges();


Delete Record

Student student = db.Students.Find(id);
db.Students.Remove(student);
db.SaveChanges();
